# Lab 07 - Amortization Schedule

**Learning Objectives:** Demonstrate input validation using `while`, use of `for` loops for repetitive tasks, and use of formatted output.

## Overview

When someone takes out an amortized loan, they're given an amortization schedule showing the payment number, monthly payment amount, interest portion, principal portion, and remaining balance after each payment. This lab builds a program that generates that schedule.

## Instructions

Validate user input (loan amount, interest rate, number of payments) using a `while` loop so bad input gets re-prompted. Then use a `for` loop to calculate and print each row of the amortization schedule: payment number, payment amount, interest paid, principal paid, and remaining balance, with formatted (2 decimal place) currency output.

Open this repo in your chosen environment (or use GitHub Codespaces) and start editing `main.py`.
